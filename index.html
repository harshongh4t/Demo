Deployment flow for eDRF XClient Container Security

Everything starts on the jumpbox. ePO supplies the connection details, deploy.sh hands them to Helm, and the DaemonSet places one agent pod on every worker. Those agents then check in with the same ePO server.

A deployment assistant for Claude and Gemini Enterprise

      
We turned the deployment guide into a reusable AI skill, edrf-xclient-deploy. Load it in Claude or Gemini Enterprise and anyone, including a first-timer, can deploy eDRF XClient by asking. It checks the jumpbox OS and deployment mode, gives each command in order with a way to confirm it worked, and diagnoses known errors.
